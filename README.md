# VLAN & STP Network Configuration

## Overview
This networking project was completed using Cisco Packet Tracer. The project focused on configuring VLANs and working with Spanning Tree Protocol (STP) in a simulated network environment.

## Technologies & Concepts
- Cisco Packet Tracer
- VLANs
- Spanning Tree Protocol (STP)
- Ethernet Switching
- Network Configuration
- Network Troubleshooting

## Project Objectives
- Configure VLANs within a switched network
- Understand VLAN segmentation and network traffic
- Configure and observe Spanning Tree Protocol
- Test connectivity between network devices
- Troubleshoot network configuration issues

## Skills Demonstrated
- Network configuration
- VLAN implementation
- Switching fundamentals
- STP fundamentals
- Network troubleshooting
- Cisco Packet Tracer
